# Ink Dynasty Tattoo Studio

A modern, high-performance React web application for **Ink Dynasty**, a premier tattoo studio. This project features resident artist showcases, an interactive portfolio gallery, cryptocurrency deposit support, and an integrated booking modal.

---

## Features

* **Artist Showcase:** Highlights resident artists, their specialties, and years of experience.
* **Interactive Portfolio Gallery:** Carousel slider displaying studio artwork.
* **Crypto Deposit System:** One-click Bitcoin address copying for booking deposits.
* **Booking Modal:** Simple form for clients to request appointments with specific artists.
* **Fully Responsive:** Styled with Tailwind CSS for seamless viewing across desktop and mobile devices.

---

## Tech Stack

* **Framework:** React
* **Styling:** Tailwind CSS
* **Icons:** Lucide React
